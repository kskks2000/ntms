# notes — 진행 중인 작업 메모

> 이 폴더는 **git이 추적하지 않습니다** (이 README만 예외).

## 왜 `docs/` 밖에 있나
`docs/` 아래 있으면 에이전트가 정식 문서로 취급해 읽습니다.
끝난 작업의 메모가 남아 있으면 **낡은 정보를 확신에 차서 따릅니다** —
문서가 없는 것보다 나쁜 상태입니다.

## 여기 넣는 것
- 조사 기록, 시행착오, 스크래치
- 작업 중 임시 정리, 붙여넣은 로그

## 종료할 때 셋 중 하나
1. **버린다** (대부분 이것)
2. 결론이 설계 결정이면 → `docs/01-decisions/`에 ADR로 승격
3. 지속적으로 참조할 사양이면 → `docs/`의 해당 번호 폴더로 이동

## 파일명 규칙
`YYYY-MM-DD-주제.md` — 날짜가 있어야 언제 것인지 판단할 수 있습니다.
