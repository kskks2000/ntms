# 00-context — 프로젝트 개요와 용어

> 최종 수정: 2026-09-04

프로젝트를 처음 접하는 사람(과 에이전트)이 **가장 먼저** 읽는 곳.
"이 프로젝트가 무엇이고, 여기서 쓰는 말이 무슨 뜻인가"만 다룬다.

## 여기 넣는 것
- 프로젝트의 목적과 해결하려는 문제
- 범위(scope)와 명시적 비범위(non-goal)
- 용어집 — 업무 용어 ↔ 코드 식별자 대응표
- 이해관계자, 주요 사용자 유형

## 넣지 않는 것
- 구체적 기능 요구 → `02-requirements/`
- 도메인 규칙과 모델 → `03-domain/`
- 기술 스택 선택 이유 → `01-decisions/`

## 예상 파일
- `개요.md`
- `용어집.md` ← **가장 중요.** 용어가 코드와 어긋나면 에이전트가 엉뚱한 걸 찾는다
- `범위.md`
