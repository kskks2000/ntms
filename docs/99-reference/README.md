# 99-reference — 참고자료와 레거시

> ⚠️ **이 폴더의 내용은 현재 코드의 동작이 아닙니다.**
> 최종 수정: 2026-09-04

기존 시스템을 분석하거나 외부 자료를 참조할 때만 읽는다.

## ⚠️ 필수 규칙
이 폴더의 **모든 문서는 첫 줄에 아래 표식을 넣는다.**

```
> ⚠️ LEGACY — 현재 코드의 동작이 아님. 참고용. (분석일: YYYY-MM-DD)
```

표식이 없으면 사람도 에이전트도 이걸 현재 사양으로 착각하고 그대로 구현합니다.
이 폴더에서 가장 흔한 사고예요.

## 여기 넣는 것
- 레거시 시스템 분석 결과
- 마이그레이션 대상 시스템의 기존 동작
- 외부 표준·규격 발췌, 벤더 문서 요약

## 넣지 않는 것
- 현재 시스템에 대한 모든 것 → 해당 번호 폴더로
- 레거시를 왜 이렇게 대체하기로 했는지 → `01-decisions/`
