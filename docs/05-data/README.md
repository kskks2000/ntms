# 05-data — 데이터 모델과 DB

> 최종 수정: 2026-09-04

조회·저장·마이그레이션 작업 전에 읽는다. `03-domain/`이 개념 모델이라면 여기는 **물리 모델**.

## 여기 넣는 것
- 테이블 구조, 관계, 인덱스 전략
- 도메인 개념 ↔ 테이블 매핑 (이름이 다르면 반드시 기록)
- 마이그레이션 규칙 — 무중단 배포를 위한 순서, 롤백 정책
- 데이터 보존·삭제 정책, 개인정보 취급 컬럼 표시

## 넣지 않는 것
- 개념 모델·불변식 → `03-domain/`
- 쿼리를 노출하는 API 스키마 → `06-api/`

## 주의
개인정보/민감정보가 들어가는 컬럼은 **문서에 실제 데이터를 예시로 넣지 않는다.**
컬럼명과 분류만 적는다.

## 예상 파일
- `스키마-<도메인>.md`
- `마이그레이션-규칙.md`
- `인덱스-전략.md`
