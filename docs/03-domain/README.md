# 03-domain — 도메인이 어떻게 동작하는가

> 최종 수정: 2026-09-04

업무 로직을 구현하기 전에 읽는 곳. 개념이 무엇이고 서로 어떤 관계이며
**깨지면 안 되는 규칙(불변식)**이 무엇인지 적는다.

## `02-requirements/`와의 경계
> 바깥에서 "바꿔 달라"고 요청할 수 있으면 `02`, 우리가 스스로 정한 동작이면 `03`.

## 여기 넣는 것
- 핵심 개념(엔티티/애그리거트)과 책임
- **불변식** — 어떤 경우에도 참이어야 하는 조건
- 상태 전이 다이어그램 (허용/금지 전이)
- 도메인 이벤트, 경계 컨텍스트

## 넣지 않는 것
- 테이블 구조·인덱스·마이그레이션 → `05-data/`
  (개념 모델과 물리 모델은 다르다. 여기는 개념만)
- 화면에서 어떻게 보이는지 → `07-ui/`
