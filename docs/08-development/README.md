# 08-development — 개발 표준

> 최종 수정: 2026-09-06

**모든 코드 작업에 적용된다.** 에이전트가 가장 자주 참조하는 폴더이므로
짧고 단정적으로 쓴다. 애매한 표현("가급적", "권장")은 지켜지지 않는다.

## 여기 넣는 것
- 네이밍 규칙, 파일·폴더 구조 컨벤션
- 에러 처리 방식 — 언제 던지고 언제 반환하는가
- 로깅 기준 — 무엇을 어떤 레벨로, 무엇을 절대 남기지 않는가
- 브랜치 전략, 커밋 메시지 규약, PR 기준
- 상태관리·데이터 페칭·빌드 설정 등 클라이언트/서버 공통 개발 규칙
- 의존성 추가 기준 (아무 라이브러리나 추가하지 않도록)
